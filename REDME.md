# 🚀 AI Code Explainer

An AI-powered web application that explains source code in simple, easy-to-understand language. Built as a college internship project using Flask and Google Gemini API.

## 📋 Features

- 🤖 **AI-Powered Analysis** - Uses Google Gemini API to explain code
- 🌐 **Multiple Languages** - Supports Python, Java, C, C++, JavaScript, PHP, HTML, CSS, SQL
- 📝 **Organized Responses** - Clear explanations in card-based format
- ⚡ **Fast & Interactive** - Instant feedback with loading spinner
- 📱 **Responsive Design** - Works on desktop and mobile
- 🎨 **Professional UI** - Modern gradient design with smooth animations

## 🛠️ Technology Stack

| Technology | Purpose |
|------------|---------|
| **Flask** | Backend web framework |
| **Google Gemini AI** | AI code explanation |
| **HTML5, CSS3** | Frontend structure and styling |
| **JavaScript** | Frontend interactivity |
| **Python** | Backend logic |
